# The Blue Art Cafe

A premium single-page website for The Blue Art Cafe — a coffee bar and rotating art gallery in Tapovan, Rishikesh, in the Himalayan foothills above the Ganga.

## Sections

- Hero — mountain sunrise scene with an animated pour
- Our Story
- Menu
- Gallery
- Team
- Visit / Contact

## Tech

Single static `index.html` — no build step, no dependencies beyond Google Fonts. Open it directly in a browser, or serve it with any static host (GitHub Pages, Netlify, Vercel, etc.).
